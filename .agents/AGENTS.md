# Workspace Rules

## Push Rule
When pushing code:
- Jangan kacau code yang sudah diubah (Do not mess with code that has already been changed).
- Hanya push code terkini (Only push the latest code).
- Code yang lama akan kekal di production jadi tiada isu (The old code will remain in production so there is no issue).

## Code Edit Rule
When editing code:
- Jangan kacau code yang sudah diubah (Do not mess with code that has already been changed).
- Hanya sentuh / ubah code yang berkaitan sahaja (Only touch/change related code).
- Jangan sentuh apa yang sudah diubah (Do not touch what has already been changed).
